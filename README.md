# 📁 高频文件夹管理器

无需手动添加，系统自动监测文件夹访问行为，统计打开频次并智能排序，自动收纳常用目录。

## ✨ 核心亮点

- **零配置自动收录** — 后台静默监控文件夹访问，达到阈值自动加入列表
- **桌面浮窗** — 始终置顶的紧凑浮窗，单击即可打开常用文件夹
- **智能排序** — 按访问频次降序排列，高频目录始终置顶
- **自动汰旧** — 长期无访问的低频目录定期清理，列表保持精简
- **一键打包** — 支持打包为独立 exe，无需 Python 环境即可运行

## 🚀 快速启动

### 方式一：直接运行 exe（推荐）

无需安装 Python，双击即可运行：

1. 前往 `dist/` 目录
2. 双击 `高频文件夹管理器.exe`

可在桌面创建快捷方式方便启动。

### 方式二：从源码运行

#### 环境要求

- Windows 10 / 11
- Python 3.10+
- 依赖库：PyQt5、pywin32

#### 安装依赖

```bash
pip install PyQt5 pywin32
```

安装 pywin32 后需执行一次初始化：

```bash
python -m pywin32_postinstall -install
```

#### 运行

```bash
python main.py
```

## 📦 打包为 exe

使用 PyInstaller 将项目打包为独立可执行文件：

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --icon=app_icon.ico --name=高频文件夹管理器 main.py
```

打包产物在 `dist/高频文件夹管理器.exe`，可独立运行，无需 Python 环境。

## 🔧 功能详解

### 1. 访问行为监听

采用双通道监控策略，覆盖面更广：

| 通道 | 原理 | 说明 |
|------|------|------|
| ExplorerMonitor | Shell.Application COM 接口 | 轮询当前打开的资源管理器窗口，捕获文件夹路径 |
| RecentFolderMonitor | Windows Recent 目录 | 扫描 `.lnk` 快捷方式，解析目标文件夹 |

### 2. 频次自动累计

每检测到一次文件夹打开事件，对应路径的访问计数 +1，同时更新最后访问时间戳。路径经过标准化处理（`Path.resolve()`），确保同一路径不会重复统计。

### 3. 智能筛选收录

- **收录阈值**：访问次数达到设定值（默认 2 次）才显示在列表中
- **自动清理**：超过指定天数未访问且频次低于阈值的目录自动移除
- **锁定保护**：手动锁定的目录不会被自动清理

### 4. 动态排序

| 排序方式 | 规则 |
|----------|------|
| 按频次排序 | 访问次数降序，高频置顶 |
| 按最近访问排序 | 最后访问时间降序 |
| 按路径排序 | 路径字母升序 |

### 5. 白名单过滤

默认排除以下系统核心目录，避免无效收录：

- `C:\Windows`
- `C:\Program Files` / `C:\Program Files (x86)`
- `C:\ProgramData`
- `C:\$Recycle.Bin`
- `C:\System Volume Information`
- `C:\Users\Public` / `C:\Users\Default`

可在设置中自定义添加。

### 6. 分组归类

按磁盘分区自动分组（如"磁盘 C"、"磁盘 D"），主界面可切换分组/平铺视图。

### 7. 本地持久化

数据存储在 `%APPDATA%/FreqFolderManager/` 目录下：

| 文件 | 内容 |
|------|------|
| `config.json` | 用户配置（阈值、白名单、浮窗位置等） |
| `folders.json` | 文件夹访问记录（路径、频次、时间戳、锁定状态） |

## ⚙ 设置项

### 通用

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 自动收录阈值 | 2 次 | 访问次数达到此值后显示在列表 |
| 监控间隔 | 3 秒 | 扫描 Explorer 窗口的间隔 |
| 关闭最小化到托盘 | 开启 | 关闭主窗口时隐藏到系统托盘 |
| 开机自动启动 | 关闭 | 开机后自动运行 |

### 浮窗

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 始终置顶 | 开启 | 浮窗始终在最前面 |
| 最大显示条目数 | 15 | 浮窗中最多显示的文件夹数量 |
| 透明度 | 92% | 浮窗背景透明度 |

### 清理

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用自动清理 | 开启 | 定期清理低活跃目录 |
| 清理阈值 | 30 天 | 超过此天数未访问可被清理 |
| 最低频次阈值 | 2 次 | 频次低于此值才可被清理 |

## 🛠 技术栈

- **语言**：Python 3.14
- **GUI 框架**：PyQt5
- **系统监控**：pywin32（Shell.Application COM、WScript.Shell）
- **数据存储**：本地 JSON 文件
- **线程安全**：`threading.Lock` 保护数据读写
- **打包工具**：PyInstaller
